# The Day Before

Браузерный 3D-шутер про выживание в зоне, захваченной зомби: деревня Сосновка и её окрестности. Написан на чистом JavaScript
и [Three.js](https://threejs.org/), без движка и без сборки. Звуки — записи настоящего
оружия и CC0-библиотек (см. `assets/audio/CREDITS.md`).

> Автобус до Сосновки больше не ходит. Эвакуация ушла без тебя. Найди три детали рации,
> вызови вертолёт с радиовышки на холме и продержись до посадки.

## Запуск

Нужен любой HTTP-сервер: ES-модули не загружаются через `file://`.

```bash
npm start          # встроенный сервер без зависимостей → http://localhost:8080
# или
npx http-server .  # или python3 -m http.server
```

Three.js лежит в `vendor/`, поэтому игра работает без интернета. Из сети грузятся только
шрифты Google Fonts; без них подставятся системные.

Нужны клавиатура и мышь. На телефоне игра не управляется.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | ходьба |
| Мышь (или стрелки) | обзор |
| Shift | бег, тратит выносливость |
| Пробел | прыжок, можно залезть на машины |
| C / Ctrl | присесть: тише шаги, зомби замечают позже |
| ЛКМ / ПКМ | выстрел или удар / прицеливание |
| R | перезарядка |
| 1–4, колесо | смена оружия |
| E | обыскать, подобрать, использовать (обыск — удерживать) |
| F | фонарик |
| H | быстрое лечение |
| Tab / I | рюкзак: ЛКМ использовать, ПКМ выбросить |
| M | карта зоны |
| Esc | пауза |

## Механики

- **Открытая зона 760×760 м** с рельефом, генерируется заново при каждом запуске:
  - деревня Сосновка: бревенчатые и крашеные избы с печью, столом и сундуками, дворы
    со штакетником, грядками, сараями и яблонями, церковь, сельпо, клуб, колодец, остановка
    и столбы ЛЭП;
  - колхоз «Заря» (амбар, коровник, силосная башня, контора), поля с сеном, озеро;
  - река с двумя деревянными мостами (вброд идти медленно);
  - трасса с АЗС и армейским блокпостом, военный лагерь с вертолётной площадкой;
  - пионерлагерь «Орлёнок» в лесу, радиовышка на холме;
  - хвойные и лиственные леса (тысячи деревьев), брошенные машины.
  Холмы закрывают обзор зомби и останавливают пули. Карта зоны — клавиша **M**.
- **Стрельба**: четыре оружия (нож, ПМ, дробовик, АКС-74У) с разбросом, отдачей, магазином,
  прицеливанием и перезарядкой из патронов в рюкзаке. Попадание в голову наносит ×2.3 урона,
  дробь слабеет с расстоянием.
- **Усталость рук**: долгое прицеливание и стрельба утомляют руки. Прицел начинает дрожать,
  отдача растёт, а на пределе рука срывается: камеру уводит рывком, оружие проваливается вниз,
  как на нательной камере. Опущенное оружие даёт рукам отдохнуть, голод и ранения ускоряют
  усталость.
- **Тихое убийство**: если подкрасться вприсядку к зомби, который тебя не заметил, нож
  наносит тройной урон.
- **Зомби** — анимированные персонажи (Quaternius, CC0) со скелетной анимацией: ходьба
  с хромотой, бег, удары, реакция на попадание, падение. Сутулая поза с вытянутыми руками
  накладывается поверх анимации. Три типа: обычные, быстрые бегуны и живучие громилы с отбрасыванием. У них
  есть зрение (угол обзора, дальность, препятствия) и слух: выстрелы и бег их приманивают.
  Застряв у стены, они обходят её.
- **Выживание**: здоровье, выносливость, голод и жажда. Укусы вызывают кровотечение.
  При сытости и без ранений здоровье восстанавливается.
- **Лут**: шкафчики, холодильники, ящики, багажники и военные ящики со своими таблицами
  добычи. Рюкзак на 20 ячеек со стаками. Из убитых зомби иногда что-то выпадает.
- **День и ночь**: игровые сутки длятся 8 минут. Ночью темно (нужен фонарик на батарейках),
  зомби больше, среди них больше бегунов.
- **Сюжет**: пеленгатор на компасе и картах ведёт к деталям рации — в конторе колхоза,
  на АЗС и в пионерлагере. Собери три, вызови эвакуацию из аппаратной у радиовышки,
  продержись 2 минуты против орды и добеги до вертолёта в военном лагере.
- **Звук**: записи настоящих выстрелов (Bersa, Benelli Nova, AK-47) с эхом, механика
  перезарядки по шагам, 3D-звук зомби (HRTF: слышно, откуда идут), шаги по траве,
  асфальту и деревянному полу, разные звуки попаданий по плоти, металлу, дереву и камню.
  Дробовик заряжается по патрону, перезарядку можно прервать выстрелом.
- **Интерфейс**: компас, миникарта, часы, лента событий, индикаторы урона и попаданий,
  меню, пауза, настройки (чувствительность, громкость, FOV, сложность, тени, разрешение
  рендера, инверсия мыши), экран итогов и рекорд в `localStorage`.

```

js/zombies.js     зомби: восприятие, движение, атаки, спавн
js/models.js      загрузка glTF-моделей зомби, анимации и поза
assets/models/    модели (glTF) и CREDITS.md
vendor/addons/    GLTFLoader и SkeletonUtils из three.js r170
js/items.js       предметы, таблицы лута, рюкзак
js/effects.js     кровь, искры, трассеры, вертолёт
js/audio.js       звук: сэмплы, 3D-панорама, реверберация, синтез
assets/audio/     CC0-звуки (MP3) и CREDITS.md
js/ui.js          HUD, компас, миникарта, инвентарь
tools/serve.mjs   статический сервер для npm start
tools/build-audio.mjs  сборка звуков из исходных записей (ffmpeg)
tools/build-models.mjs сборка моделей зомби (gltf-transform)
tests/e2e.mjs     сквозной тест всех механик
```

## Тесты

```bash
npm install   # ставит Playwright
npm test
```

Тест открывает игру в headless Chromium на фиксированной карте (`?seed=42`) и проверяет
58 сценариев: движение, коллизии, стрельбу, перезарядку, нож, усталость рук, звук, поведение зомби, обыск,
инвентарь, кровотечение, голод, ночь и фонарик, весь сюжет до победы, смерть, паузу,
оружие и настройки, плюс проверку генератора на 5 случайных картах (двери, контейнеры, пульт,
старт, площадка). Время в тесте идёт через `window.__game.tick()`, поэтому результат
не зависит от FPS. Скриншоты сохраняются в `test-results/`.
